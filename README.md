## 🛠️ Technology Stack

* **Frontend:** React 18, TypeScript, Vite, TailwindCSS (HSL Amber Theme), Framer Motion, Axios, Leaflet Map.
* **Backend:** FastAPI (Python 3.11), SQLModel (SQLAlchemy), Pydantic, Uvicorn, Pydub.
* **Database:** Relational SQLModel Database (SQLite for local dev, PostgreSQL for production scaling).
* **AI Orchestration:** ElevenLabs v2 Multilingual, Pollinations Flux Realism image diffusion, Microsoft Edge-TTS local fallback.

## 🚀 Getting Started & Local Playback

### 1. Backend Server Setup
Ensure you have Python 3.11 installed:
```bash
cd backend
pip install -r requirements.txt

# Run the backend API server
uvicorn app.main:app --host 0.0.0.0 --port 2000
```
*API Docs will be available at: `http://localhost:2000/docs`*

### 2. Frontend Client Setup
Ensure you have Node.js 18+ installed:
```bash
cd frontend
npm install
npm run dev
```
*The web dashboard will launch at: `http://localhost:5173`*
